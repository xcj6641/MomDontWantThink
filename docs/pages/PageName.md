🧠 一些关键命名原则（帮你后续统一风格）

你这个产品建议统一用这一套语义：

Plan = 计划（周维度）
Meal = 餐次（一天内）
Recipe = 菜品
Meal Prep = 备餐（很关键，选得很好 👍）
