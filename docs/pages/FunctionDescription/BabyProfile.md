# 宝宝档案页（Baby Profile）产品描述

## 一、页面定位

宝宝档案页是"我的"Tab 的主页面，用于：

- 展示宝宝当前基础信息摘要（宝宝信息卡）
- 提供进入档案编辑页的入口
- 聚合宝宝相关功能模块入口（进食记录、过敏信息等）

---

## 二、页面结构

### 1. 宝宝信息卡

位于页面顶部，展示宝宝当前状态摘要。

#### 有宝宝信息时

展示内容：

- 宝宝图标（👶）
- 宝宝月龄：`宝宝 · X个月`
- 每日餐次：`X餐/天`（根据月龄由 `ageMealConfig` 计算）
- 出牙阶段（仅在已设置时展示）
- 过敏食材摘要（仅在有过敏食材时展示，最多显示 2 项，超出显示 `…`）
- 编辑按钮：`编辑` → 进入档案编辑页

#### 出牙阶段展示

显示格式：`出牙：未出牙` / `出牙：上下门牙` / `出牙：上下后槽牙`

| 内部值 | 显示文案 |
|--------|---------|
| `none` | 出牙：未出牙 |
| `incisors` | 出牙：上下门牙 |
| `molars` | 出牙：上下后槽牙 |
| 未设置 | 不展示此行 |

数据来源：`getPreferences` 返回的 `teethStage` 字段。

刷新时机：每次页面 `onShow` 时重新拉取，用户在档案编辑页修改出牙阶段并保存后返回，信息自动更新。

#### 无宝宝信息时

- 显示文案：`还没有宝宝信息`
- 按钮文案：`去填写` → 进入档案编辑页

---

### 2. 功能列表

#### 宝宝模块

- **进食记录** → 进入进食日志页
- **过敏信息** → 进入档案编辑页（过敏食材区域）

#### 我的内容模块

- **宝宝喜欢** → 宝宝喜欢的菜品列表
- **我的菜谱** → 用户自建菜谱列表
- **收藏的菜谱** → 用户收藏的菜谱
- **收藏的周计划** → 用户收藏的周计划模板

#### 设置模块

- **备餐提醒** → 提醒设置页
- **关于我们** → 应用信息
- **Mock 模式** → 开发调试用，周计划本地模拟开关

---

## 三、档案编辑页

从宝宝信息卡点击"编辑"进入。

### 编辑字段

| 字段 | 类型 | 必填 |
|------|------|------|
| 宝宝名字 | 文本输入 | 否 |
| 宝宝月龄 | 数字输入 | 是 |
| 出牙阶段 | 分段单选（3选1） | 否 |
| 过敏/忌口食材 | 文本域（逗号分隔） | 否 |
| BLW 喜欢 | 文本域 | 否 |
| BLW 不喜欢 | 文本域 | 否 |

### 出牙阶段选择器

三个等宽横排选项：

| 选项 | 内部值 | 食物形态指引 |
|------|--------|-------------|
| 未出牙 | `none` | 细腻泥糊 |
| 上下门牙 | `incisors` | 软烂小块 |
| 上下后槽牙 | `molars` | 可嚼小块 |

交互规则：
- 点击选中，高亮显示（绿色主题色）
- 再次点击同一项取消选中（可不选）
- 当前选中项在编辑页加载时自动回填

保存行为：
- 点击"保存偏好"将 `teethStage` 一并提交至 `savePreferences` 云函数
- 返回宝宝档案页后，宝宝信息卡自动刷新展示最新出牙阶段

---

## 四、数据流

```
getPreferences（云函数）
  └─ 返回 teethStage、babyAgeMonths、allergyIngredientNames 等
        ├─ 宝宝信息卡：展示 teethStageLine、allergyText
        └─ 档案编辑页：回填 teethStage 选中状态

savePreferences（云函数）
  └─ 接收 teethStage、babyName、babyAgeMonths、allergyIngredientNames 等
        └─ 保存后，返回宝宝档案页 onShow 触发刷新
```

---

## 五、跨页面同步

出牙阶段在以下页面均有展示，均通过各自的 `onShow` 自动刷新：

| 页面 | 展示位置 | 数据来源云函数 |
|------|---------|--------------|
| 今日辅食页 | 宝宝信息卡 | `getHomeData` |
| 宝宝档案页 | 宝宝信息卡 | `getPreferences` |

用户在档案编辑页修改出牙阶段并保存后，返回或切换至上述任一页面均会自动展示最新值。
