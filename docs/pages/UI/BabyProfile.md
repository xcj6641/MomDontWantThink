# Baby Profile 页面设计说明（我的）

本文档描述 **`pages/me`** 页面的 UI 设计。  
编辑子页（宝宝信息填写表单）位于 **`pages/profile`**，通过顶部卡片右侧「编辑」按钮进入。

---

## 一、页面定位

- **入口**：底部 Tab 栏「我的」
- **角色**：个人中心 —— 一眼看清宝宝状态，快速进入内容列表与设置
- **气质**：暖白绿、简洁，卡片层级与本周计划页保持一致

---

## 二、纵向信息架构（从上到下）

| 顺序 | 模块 | 说明 |
|------|------|------|
| 1 | 宝宝信息卡 | 显示宝宝月龄、餐次、过敏；右上角文字编辑按钮 |
| 2 | 宝宝卡片 | 进食记录 + 过敏信息，2 行 |
| 3 | 我的内容卡片 | 宝宝喜欢 / 我的菜谱 / 收藏菜谱 / 收藏周计划，4 行 |
| 4 | 设置卡片 | 备餐提醒 / 关于我们 / Mock 模式，3 行 |
| 5 | 底部安全区 | `safe-area` 占位 |

---

## 三、宝宝信息卡（`.baby-bar`）

遵循「头部信息区设计风格规范」。

### 3.1 容器

- **布局**：`grid`，`grid-template-columns: max-content 1fr`，`column-gap: 20rpx`，`align-items: start`
- **背景**：`linear-gradient(165deg, #fbfdf9 0%, #eef6f1 40%, #dff5ea 100%)`
- **边框**：`2rpx solid rgba(160, 216, 192, 0.40)`
- **圆角**：`32rpx`；**内边距**：`32rpx`；**阴影**：`0 6rpx 20rpx rgba(47,94,59,0.05)`

### 3.2 布局结构

```
┌──────────────────────────────────────┐
│ 👶  宝宝 · 7个月               编辑 │
│     2餐/天                           │
│     过敏：鸡蛋（有过敏时展示）        │
└──────────────────────────────────────┘
```

- **左列**：`👶` emoji，`44rpx / line-height: 1`，仅有宝宝信息时显示
- **右列**（`baby-bar-top`，`flex row / align-items: flex-start / justify-content: space-between`）：
  - **左侧文字区**（`baby-bar-head`，`flex column / gap: 10rpx`）：
    - 主标题：`宝宝 · X个月`，`34rpx / 600 / #2f5e3b / line-height: 1`
    - 餐次行：`X餐/天`，`24rpx / #7d8b80 / line-height: 1.45`
    - 过敏行（可选，有过敏时显示）：`过敏：…`，`24rpx / #7d8b80`
  - **右侧操作**（`baby-bar-actions`，顶部对齐）：
    - 文字按钮 `编辑` / `去填写`，`26rpx / 500 / #6ba86a`

### 3.3 无宝宝信息状态

- emoji 隐藏；`baby-bar-top` 占满全宽
- 主标题替换为 `还没有宝宝信息`，颜色 `#7d8b80 / font-weight: 400`
- 右侧显示 `去填写`

## 四、列表卡片通用规范

三张卡片（宝宝 / 我的内容 / 设置）样式完全一致，无标题标签。

- **容器**：白底，`32rpx` 圆角，`1rpx solid #e4ede6` 边框，`box-shadow: 0 4rpx 16rpx rgba(90,120,95,0.05)`
- **分割线**：`1rpx / rgba(160,216,192,0.25)` 绿色调细线，`margin: 0 32rpx`
- **行高**：`min-height: 96rpx`；`padding: 0 32rpx`
- **行结构**：`[图标 40rpx] [文字区 flex:1] [箭头 ›]`
- **图标**：彩色 line 风格 SVG，`40×40rpx`，存放于 `assets/icons/me/`
- **标题**：`28rpx / #2f3a35`
- **副标题**：`24rpx / #7d8b80`
- **箭头**：`›`，`32rpx / #c0ccc4`

## 九、视觉规范

- **页面背景**：`#f7f8fa`，页面 padding `24rpx`（遵循全局规范）
- **信息卡**：遵循「头部信息区设计风格规范」，grid 布局，`align-items: start`
- **图标**：彩色 line SVG，`stroke-width: 1.5`，`fill: none`，各有专属色
- **分割线**：绿色调低透明度 `rgba(160,216,192,0.25)`，仅用于卡片内行间

---

## 十、数据与接口

- **宝宝信息**（月龄、过敏）：`getPreferences` 云函数；月龄用于计算餐次数（`getOrderedSlotsForAge`）
- **内容数量**：本地存储计数或专项查询；暂无数据时按各行规则处理（显示或隐藏副标题）
